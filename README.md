## Quick-Start Guide

<div class="steps-grid">
  <div class="step-card">
    <div class="step-number">1</div>
    <div class="step-title">Diagnose</div>
    <div class="step-desc">Take the <a href="{{ site.baseurl }}/readiness/">readiness self-check</a>. If proof-based analysis or linear algebra is shaky, begin with <a href="{{ site.baseurl }}/module_0/">Module 0</a>; it is what every later module assumes.</div>
  </div>
  <div class="step-card">
    <div class="step-number">2</div>
    <div class="step-title">Build the Core</div>
    <div class="step-desc">Real Analysis and Matrix Analysis (Module A) establish the shared language (metric spaces, spectral theory, matrix decompositions) used throughout the later modules.</div>
  </div>
  <div class="step-card">
    <div class="step-number">3</div>
    <div class="step-title">Add Probability Early</div>
    <div class="step-desc">Start Probability Theory I alongside Module A. It is the third Introductory Exam paper, and its measure theory reinforces the analysis.</div>
  </div>
  <div class="step-card">
    <div class="step-number">4</div>
    <div class="step-title">Choose a Track</div>
    <div class="step-desc">Statistics: Modules B and C. Applied mathematics: Modules F and D. Use the <a href="{{ site.baseurl }}/computing_lab/">Computing Lab</a> to verify every rate and bound numerically.</div>
  </div>
  <div class="step-card">
    <div class="step-number">5</div>
    <div class="step-title">Practice Exams</div>
    <div class="step-desc">After Module A and Probability Theory I, sit the three <a href="{{ site.baseurl }}/qualifying_exam/">practice papers</a> under real conditions (3 hours each, closed book), then move on to the department's past papers.</div>
  </div>
</div>

## Technical Notes

- **Math Rendering** — All LaTeX notation is rendered client-side by [MathJax 3](https://www.mathjax.org/). Use `$...$` for inline math and `$$...$$` for displayed equations. Inside Markdown tables, write absolute values as `\lvert x \rvert`, because a bare `|` ends the table cell.
- **Callouts** — Use `{: .important }`, `{: .note }`, or `{: .warning }` on the line before a `>` blockquote. (GitHub-style `> [!NOTE]` alerts are not rendered by Jekyll's kramdown.)
- **Collapsible sections** — Write `<details markdown="1">` so that Markdown inside the block is rendered.
- **GitHub Pages** — Enable Pages from **Settings → Pages → Branch: main → / (root)**. The site builds automatically via Jekyll.
- **Local Preview** — Install Ruby, run `bundle install`, then `bundle exec jekyll serve`. The site will be available at `http://localhost:4000/math-phd-study/`.
