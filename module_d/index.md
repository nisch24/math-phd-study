## Prerequisites

- **Module A**: Real Analysis (continuity, compactness, Inverse Function Theorem)
- **Module A**: Matrix Analysis (positive definiteness, eigenvalue characterizations)
- Multivariable calculus (gradients, Hessians, Taylor expansions)

## Connection to Other Modules

- **Module C (Statistics)** — MLE, EM algorithm, and penalized regression are optimization problems.
- **Module B (Probability)** — Stochastic gradient descent and Monte Carlo optimization bridge both fields.
