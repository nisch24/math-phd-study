# EN.553.720 — Probability Theory I

> *A rigorous, measure-theoretic development of probability. This course builds the foundational machinery — $\sigma$-algebras, measures, Lebesgue integration, and modes of convergence — required for modern probability and mathematical statistics.*

---

## Learning Objectives

Upon completing this module, the student will be able to:

1. **Construct probability spaces** using $\sigma$-algebras, measures, and measurable functions.
2. **Define and compute Lebesgue integrals** and relate them to probabilistic expectation.
3. **Distinguish modes of convergence**: almost sure, in probability, in $L^p$, and in distribution.
4. **Prove and apply the Laws of Large Numbers** (Weak and Strong forms).
5. **Apply characteristic functions** to establish the Central Limit Theorem.

## Core Theory

### Unit 1: Measure-Theoretic Foundations

#### 1.1 $\sigma$-Algebras

**Definition**: A **$\sigma$-algebra** $\mathcal{F}$ on a set $\Omega$ is a collection of subsets satisfying:

1. $\Omega \in \mathcal{F}$.
2. If $A \in \mathcal{F}$, then $A^c \in \mathcal{F}$ (closed under complementation).
3. If $A_1, A_2, \ldots \in \mathcal{F}$, then $\bigcup_{n=1}^\infty A_n \in \mathcal{F}$ (closed under countable unions).

**Key Examples**:
- **Trivial $\sigma$-algebra**: $\{\emptyset, \Omega\}$.
- **Power set**: $2^\Omega$ (all subsets of $\Omega$).
- **Borel $\sigma$-algebra** $\mathcal{B}(\mathbb{R})$: the smallest $\sigma$-algebra containing all open sets in $\mathbb{R}$, generated by intervals $(-\infty, a]$.

**Theorem**: For any collection of subsets $\mathcal{C}$, there exists a unique smallest $\sigma$-algebra $\sigma(\mathcal{C})$ containing $\mathcal{C}$ (the $\sigma$-algebra *generated by* $\mathcal{C}$).

#### 1.2 Probability Measures

**Definition**: A **probability measure** on $(\Omega, \mathcal{F})$ is a function $P: \mathcal{F} \to [0,1]$ satisfying:

1. $P(\Omega) = 1$.
2. **Countable additivity**: for pairwise disjoint $A_1, A_2, \ldots \in \mathcal{F}$:

$$P\!\left(\bigcup_{n=1}^\infty A_n\right) = \sum_{n=1}^\infty P(A_n).$$

The triple $(\Omega, \mathcal{F}, P)$ is called a **probability space**.

**Continuity Properties**:
- If $A_n \uparrow A$, then $P(A_n) \uparrow P(A)$ (continuity from below).
- If $A_n \downarrow A$, then $P(A_n) \downarrow P(A)$ (continuity from above).
- **Borel-Cantelli I**: If $\sum P(A_n) < \infty$, then $P(A_n \text{ i.o.}) = 0$.
- **Borel-Cantelli II**: If $A_n$ are independent and $\sum P(A_n) = \infty$, then $P(A_n \text{ i.o.}) = 1$.

#### 1.3 Random Variables and Measurability

**Definition**: A **random variable** is a measurable function $X: (\Omega, \mathcal{F}) \to (\mathbb{R}, \mathcal{B}(\mathbb{R}))$, meaning $X^{-1}(B) \in \mathcal{F}$ for all $B \in \mathcal{B}(\mathbb{R})$.

The **distribution** (law) of $X$ is the pushforward measure $\mu_X(B) = P(X \in B)$ on $(\mathbb{R}, \mathcal{B}(\mathbb{R}))$.

The **cumulative distribution function**: $F_X(x) = P(X \leq x)$.

### Unit 2: Lebesgue Integration and Expectation

#### 2.1 Construction of the Lebesgue Integral

The Lebesgue integral is constructed in three stages:

**Step 1 — Simple functions**: For $\varphi = \sum_{i=1}^n a_i \mathbf{1}_{A_i}$ with $A_i \in \mathcal{F}$ pairwise disjoint:

$$\int \varphi \, dP = \sum_{i=1}^n a_i P(A_i).$$

**Step 2 — Nonnegative measurable functions**: For $f \geq 0$:

$$\int f \, dP = \sup\left\{\int \varphi \, dP : 0 \leq \varphi \leq f,\; \varphi \text{ simple}\right\}.$$

**Step 3 — General measurable functions**: Write $f = f^+ - f^-$ where $f^+ = \max(f, 0)$ and $f^- = \max(-f, 0)$. Then $\int f\, dP = \int f^+\, dP - \int f^-\, dP$, provided at least one integral is finite. We say $f$ is **integrable** (i.e., $f \in L^1$) if $\int |f|\, dP < \infty$.

#### 2.2 Fundamental Convergence Theorems

**Monotone Convergence Theorem (MCT)**: If $0 \leq f_n \uparrow f$ almost surely, then:

$$\int f_n \, dP \uparrow \int f \, dP.$$

**Fatou's Lemma**: If $f_n \geq 0$, then:

$$\int \liminf_{n \to \infty} f_n \, dP \leq \liminf_{n \to \infty} \int f_n \, dP.$$

**Dominated Convergence Theorem (DCT)**: If $f_n \to f$ a.s. and $|f_n| \leq g$ for some integrable $g$, then:

$$\lim_{n \to \infty} \int f_n \, dP = \int f \, dP.$$

#### 2.3 Expectation as Lebesgue Integral

For a random variable $X$ with distribution $\mu_X$:

$$E[X] = \int_\Omega X(\omega) \, dP(\omega) = \int_{\mathbb{R}} x \, d\mu_X(x).$$

**$L^p$ Spaces**: $X \in L^p$ if $E[|X|^p] < \infty$. Key inequalities:
- **Jensen's Inequality**: If $\varphi$ is convex, then $\varphi(E[X]) \leq E[\varphi(X)]$.
- **Hölder's Inequality**: $E[|XY|] \leq (E[|X|^p])^{1/p}(E[|Y|^q])^{1/q}$ for $1/p + 1/q = 1$.
- **Minkowski's Inequality**: $(E[|X+Y|^p])^{1/p} \leq (E[|X|^p])^{1/p} + (E[|Y|^p])^{1/p}$.

### Unit 3: Independence and Product Measures

#### 3.1 Independence

Events $A_1, \ldots, A_n$ are **independent** if for every subset $I \subseteq \{1, \ldots, n\}$:

$$P\!\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i).$$

Random variables $X_1, \ldots, X_n$ are independent if the generated $\sigma$-algebras $\sigma(X_1), \ldots, \sigma(X_n)$ are independent.

**Theorem**: $X_1, \ldots, X_n$ are independent if and only if $F_{X_1, \ldots, X_n}(x_1, \ldots, x_n) = \prod_i F_{X_i}(x_i)$.

#### 3.2 Product Measures and Fubini's Theorem

**Theorem (Fubini-Tonelli)**: Let $(\Omega_i, \mathcal{F}_i, \mu_i)$ be $\sigma$-finite measure spaces. If $f \geq 0$ is measurable on the product space, or if $f$ is integrable with respect to $\mu_1 \times \mu_2$:

$$\int f \, d(\mu_1 \times \mu_2) = \int \left(\int f(x,y) \, d\mu_2(y)\right) d\mu_1(x) = \int \left(\int f(x,y) \, d\mu_1(x)\right) d\mu_2(y).$$

### Unit 4: Modes of Convergence and Limit Theorems

#### 4.1 Modes of Convergence

For random variables $X_n$ and $X$:

| Mode | Notation | Definition |
|------|----------|------------|
| Almost sure | $X_n \xrightarrow{\text{a.s.}} X$ | $P(\lim_{n\to\infty} X_n = X) = 1$ |
| In probability | $X_n \xrightarrow{P} X$ | $P(\|X_n - X\| > \varepsilon) \to 0$ for all $\varepsilon > 0$ |
| In $L^p$ | $X_n \xrightarrow{L^p} X$ | $E[\|X_n - X\|^p] \to 0$ |
| In distribution | $X_n \xrightarrow{d} X$ | $F_{X_n}(x) \to F_X(x)$ at all continuity points of $F_X$ |

**Implications**: a.s. $\Rightarrow$ in probability $\Rightarrow$ in distribution. $L^p \Rightarrow$ in probability. No other general implications hold without additional conditions.

#### 4.2 The Weak Law of Large Numbers

**Theorem (WLLN)**: Let $X_1, X_2, \ldots$ be i.i.d. with $E[X_1] = \mu$ and $\operatorname{Var}(X_1) = \sigma^2 < \infty$. Then:

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{P} \mu.$$

*Proof*: By Chebyshev's inequality: $P(|\bar{X}_n - \mu| > \varepsilon) \leq \frac{\sigma^2}{n\varepsilon^2} \to 0$.

#### 4.3 The Strong Law of Large Numbers

**Theorem (Kolmogorov SLLN)**: Let $X_1, X_2, \ldots$ be i.i.d. with $E[|X_1|] < \infty$. Then:

$$\bar{X}_n \xrightarrow{\text{a.s.}} E[X_1].$$

The proof via the fourth-moment method (under finite fourth moment) or via truncation arguments is substantially more involved than the WLLN.

#### 4.4 The Central Limit Theorem

**Theorem (Lindeberg-Lévy CLT)**: Let $X_1, X_2, \ldots$ be i.i.d. with $E[X_1] = \mu$ and $\operatorname{Var}(X_1) = \sigma^2 \in (0, \infty)$. Then:

$$\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \xrightarrow{d} N(0, 1).$$

*Proof Strategy (Characteristic Functions)*: Let $\varphi(t)$ be the characteristic function of $(X_i - \mu)/\sigma$. Then $\varphi(t) = 1 - t^2/2 + o(t^2)$ as $t \to 0$. The characteristic function of the normalized sum satisfies $[\varphi(t/\sqrt{n})]^n \to e^{-t^2/2}$, which is the characteristic function of $N(0,1)$. Lévy's Continuity Theorem then gives convergence in distribution.

## Problem Sets

### Problem Set 1: Measure-Theoretic Foundations

1. **(Durrett 1.1)** Show that $\mathcal{F}_1 \cap \mathcal{F}_2$ is a $\sigma$-algebra whenever $\mathcal{F}_1$ and $\mathcal{F}_2$ are, but $\mathcal{F}_1 \cup \mathcal{F}_2$ generally is not.
2. **(Exam-style)** Prove Borel-Cantelli Lemma I: if $\sum P(A_n) < \infty$, then $P(\limsup A_n) = 0$.
3. **(Exam-style)** Let $(X_n)$ be a sequence of random variables. Prove that the event $\{X_n \to X\}$ is measurable (i.e., $\{X_n \to X\} \in \mathcal{F}$).
4. **(Proof)** Construct a probability measure on $((0,1], \mathcal{B}((0,1]))$ corresponding to the uniform distribution by defining it on intervals and extending via Carathéodory's Extension Theorem.
5. **(Challenge)** Prove that $\mathcal{B}(\mathbb{R})$ is generated by $\{(-\infty, q] : q \in \mathbb{Q}\}$.

### Problem Set 2: Integration and Convergence Theorems

1. **(Durrett 1.5)** Use the MCT to prove Fatou's Lemma.
2. **(Exam-style)** Compute $\lim_{n \to \infty} \int_0^n \left(1 - \frac{x}{n}\right)^n e^{x/2} \, dx$ using the Dominated Convergence Theorem.
3. **(Exam-style)** Prove: if $E[X^2] < \infty$, then $E[X]$ is finite. More generally, show $L^q \subseteq L^p$ for $q > p \geq 1$ on finite measure spaces.
4. **(Proof)** Prove Jensen's inequality using the supporting hyperplane characterization of convex functions.
5. **(Application)** Let $X \geq 0$ be a random variable. Show that $E[X] = \int_0^\infty P(X > t) \, dt$.

### Problem Set 3: Laws of Large Numbers and CLT

1. **(Durrett 2.2)** Prove the WLLN using Chebyshev's inequality.
2. **(Exam-style)** Prove that a.s. convergence implies convergence in probability, but not conversely. Construct an explicit counterexample.
3. **(Exam-style)** State and prove the Lindeberg-Lévy CLT using characteristic functions.
4. **(Application)** Use the CLT to approximate $P(S_{100} > 520)$ where $S_{100} = X_1 + \cdots + X_{100}$ and $X_i$ are i.i.d. with $E[X] = 5$ and $\operatorname{Var}(X) = 4$.
5. **(Challenge)** Prove or disprove: convergence in distribution implies convergence of expectations.

## Study Guide &amp; Exam Preparation

> [!IMPORTANT]
> **Key Theorems for the Qualifying Exam (Probability Portion)**
>
> The following results appear most frequently and must be mastered at the full-proof level:
> - **Borel-Cantelli Lemmas** (both I and II) — the "almost infinitely often" criterion
> - **Monotone Convergence Theorem** — nonnegative increasing functions; swap limit and integral
> - **Dominated Convergence Theorem** — the workhorse for computing limits of integrals
> - **WLLN** — Chebyshev + independence; the standard proof
> - **SLLN** — know the statement; be familiar with the truncation proof strategy
> - **CLT** — characteristic function proof; state Lévy's Continuity Theorem when using it

**Common Exam Question Types**:
- *"Use the DCT to compute $\lim_{n\to\infty} \int \ldots$"* — identify the dominating function explicitly.
- *"Prove a.s. convergence using Borel-Cantelli"* — verify $\sum P(A_n) < \infty$.
- *"Apply the CLT to a concrete setting"* — standardize, identify $\mu$ and $\sigma^2$, then invoke.
