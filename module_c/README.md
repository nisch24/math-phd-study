# Module C — Statistics & Statistical Learning

> **From data to inference.** Statistical Theory provides the rigorous framework for estimation, hypothesis testing, and the asymptotic behavior of estimators. These courses bridge probability theory with the practical tools used in every area of applied mathematics.

---

## Courses

| Code | Title | Key Topics |
|------|-------|------------|
| [EN.553.730](statistical_theory_1/lesson_plan) | Statistical Theory I | Sufficiency, Fisher Information, Cramér-Rao, UMVUE |
| [EN.553.731](statistical_theory_2/lesson_plan) | Statistical Theory II | Neyman-Pearson, LRT, MLE asymptotics |

## Prerequisites

- Module B: Probability Theory I & II (measure-theoretic probability, convergence theorems)
- Module A: Matrix Analysis (covariance matrices, spectral decomposition)

## Connection to Other Modules

- **Module D (Optimization)**: Maximum likelihood estimation is an optimization problem; Fisher scoring is Newton's method on the log-likelihood.
- **Computing Lab**: R and Python implementations of estimators, bootstrap methods, and simulation studies.
