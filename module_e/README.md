# Module E — Discrete Mathematics

> **Counting, structure, and algorithms.** Discrete mathematics provides essential tools for combinatorial probability, algorithm analysis, and network optimization. This module covers both enumerative combinatorics and structural graph theory.

---

| Code | Title | Key Topics |

| [EN.553.672](graph_theory/lesson_plan) | Graph Theory | Eulerian/Hamiltonian circuits, network flows, coloring |

## Prerequisites

- Undergraduate discrete mathematics or combinatorics
- Proof-writing maturity (mathematical induction, pigeonhole principle)

## Connection to Other Modules

- **Module B (Probability)**: Combinatorial arguments underpin discrete probability distributions and random graph theory.
- **Module D (Optimization)**: Network flows, shortest path, and matching are combinatorial optimization problems.
