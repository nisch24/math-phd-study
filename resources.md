# 📚 Resources — Open-Access Lecture Notes &amp; Materials

> *A curated collection of free, high-quality mathematical resources organized by module. All links point to materials freely available from university servers, arXiv, or open-access repositories — no authentication required.*

> [!NOTE]
> Links were verified as of March 2026. If a link is broken, search for the course title and institution name on the host institution's website or on MIT OCW's search page.

---

<details open>
<summary><strong>Module A: Analysis &amp; Linear Algebra</strong></summary>

*The resources below cover the two pillars of Module A: rigorous real analysis in the tradition of Rudin, and the modern spectral-theoretic view of linear algebra.*

### Real Analysis

| Resource | Source | Description |
|----------|--------|-------------|
| [MIT 18.100A Real Analysis](https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/) | MIT OCW | Full course with lecture notes, problem sets, and exams |
| [MIT 18.100B Analysis I](https://ocw.mit.edu/courses/18-100b-analysis-i-fall-2010/) | MIT OCW | Rudin-based, with complete problem sets |
| [Francis Su — Real Analysis Lectures](https://www.youtube.com/playlist?list=PL04BA7A9B8C57B2F0) | Harvey Mudd | 34 video lectures based on *Baby Rudin* |
| [Terence Tao — Analysis I &amp; II](https://terrytao.wordpress.com/books/analysis-i/) | UCLA | Companion blog with errata and supplementary exercises |

### Linear Algebra &amp; Matrix Analysis

| Resource | Source | Description |
