# 📚 Resources — Open-Access Lecture Notes &amp; Materials

> *A curated collection of free, high-quality mathematical resources organized by module. Everything listed is freely available from university servers, author sites, or open courseware.*

{: .note }
> Links were last checked in November 2026. A few university sites block automated link checkers, so a link marked as working may still occasionally move. If one breaks, search the course number and institution, or use MIT OCW's site search.

---

<details open markdown="1">
<summary><strong>Module 0: Foundations (Bridge Material)</strong></summary>

*For anyone whose undergraduate math was computational rather than proof-based. These courses are where proof writing is actually taught.*

| Resource | Source | Description |
|----------|--------|-------------|
| [MIT 6.042J Mathematics for Computer Science](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/) | MIT OCW | Proofs, induction, counting, discrete probability; ideal bridge from CS |
| [MIT 18.100A Real Analysis](https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/) | MIT OCW | First course in analysis on $\mathbb{R}$, with video lectures |
| [MIT 18.700 Linear Algebra](https://ocw.mit.edu/courses/18-700-linear-algebra-fall-2013/) | MIT OCW | Proof-based linear algebra (vector spaces, linear maps, spectral theory) |
| [Sheldon Axler — Linear Algebra Done Right](https://linear.axler.net/) | Author's site | Free electronic edition; proof-based, determinant-free |
| [MIT 18.600 Probability and Random Variables](https://ocw.mit.edu/courses/18-600-probability-and-random-variables-fall-2019/) | MIT OCW | Calculus-based probability at the level of Ross |
| [MIT 18.650 Statistics for Applications](https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/) | MIT OCW | Rigorous introduction to statistical inference |

</details>

<details markdown="1">
<summary><strong>Module A: Analysis &amp; Linear Algebra</strong></summary>

*The two pillars of Module A: rigorous real analysis in the tradition of Rudin, and the spectral-theoretic view of linear algebra.*

### Real Analysis

| Resource | Source | Description |
|----------|--------|-------------|
| [MIT 18.100B Analysis I](https://ocw.mit.edu/courses/18-100b-analysis-i-fall-2010/) | MIT OCW | Rudin-based, with complete problem sets |
| [MIT 18.100A Real Analysis](https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/) | MIT OCW | Full course with lecture notes, problem sets, and exams |
| [Francis Su — Real Analysis Lectures](https://www.youtube.com/playlist?list=PL04BA7A9B8C57B2F0) | Harvey Mudd | Recorded lecture course based on *Baby Rudin* |
| [Terence Tao — Analysis I &amp; II](https://terrytao.wordpress.com/books/analysis-i/) | UCLA | Companion page with errata for a very careful, beginner-friendly text |

### Linear Algebra &amp; Matrix Analysis

| Resource | Source | Description |
|----------|--------|-------------|
| [MIT 18.06SC Linear Algebra](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) | MIT OCW | Gilbert Strang's course; builds geometric intuition (computational, not proof-based) |
| [MIT 18.065 Matrix Methods](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/) | MIT OCW | SVD, low rank, and matrix methods for data analysis |
| [MIT 18.335J Introduction to Numerical Methods](https://ocw.mit.edu/courses/18-335j-introduction-to-numerical-methods-spring-2019/) | MIT OCW | Numerical linear algebra: conditioning, stability, QR, eigenvalue algorithms |
| [Sheldon Axler — Linear Algebra Done Right](https://linear.axler.net/) | Author's site | Free electronic edition; proof-based, no determinants |

</details>

<summary><strong>Module B: Probability &amp; Stochastic Processes</strong></summary>

*These resources develop probability from a measure-theoretic foundation, through martingales, to the beginnings of stochastic calculus.*

| Resource | Source | Description |
|----------|--------|-------------|
| [MIT 18.175 Theory of Probability](https://ocw.mit.edu/courses/18-175-theory-of-probability-spring-2014/) | MIT OCW | Measure-theoretic graduate probability following Durrett (Sheffield) |

| [Stanford STATS 310A](https://web.stanford.edu/class/stats310a/) | Stanford | Course page for Stanford's measure-theoretic probability sequence |
| [MIT 18.445 Introduction to Stochastic Processes](https://ocw.mit.edu/courses/18-445-introduction-to-stochastic-processes-spring-2015/) | MIT OCW | Markov chains, mixing, random walks, martingales |

</details>
